# 🏅 Olympic Medals Prediction

## 📌 Project Overview

This project uses **Machine Learning and Linear Regression** to predict the number of Olympic medals a team may win based on historical team data.

## 🎯 Objective

The main objective is to build a regression model that predicts:

- `medals` — total medals won by a team

using:

- `athletes` — number of athletes
- `prev_medals` — medals won previously

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## 🔄 Project Workflow

1. Load the Olympic team dataset
2. Clean and preprocess the data
3. Handle missing values
4. Split the data into training and testing datasets
5. Select relevant features
6. Train a Linear Regression model
7. Generate medal predictions
8. Evaluate model performance

## 🤖 Machine Learning Model

**Algorithm:** Linear Regression
